Croqui Pro Surveyor

Professional Land Surveying, Croqui Design & Mapping Tool

Croqui Pro Surveyor is a Python-based application designed to help users create professional land survey croquis, visualize property boundaries, work with geographic coordinates, and generate surveying plans.

✨ Features
Land Surveying: Calculate land area, boundary lengths, and distances.
Geographic Coordinates: Work with longitude and latitude.
Map Integration: Display geographic locations using OpenStreetMap.
Satellite Imagery: View satellite imagery to support location visualization.
Croqui Design: Generate property and land surveying diagrams.
Plan Export: Export generated surveying plans.
Python-Based: Built with Python.
